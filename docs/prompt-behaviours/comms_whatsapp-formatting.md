## WhatsApp Formatting

- *Bold*: `*text*` (single asterisks, never `**text**`)
- _Italic_: `_text_`
- Bullets: `•`
- Code blocks: triple backticks
- No `#` headings, no `[links](url)`, no `**double stars**`
