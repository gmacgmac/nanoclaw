## Procedure-Based Context Building

For structured feature work, build context before coding:

1. Read the relevant `procedures/*.md` to understand the workflow
2. Gather context — files, dependencies, interfaces involved
3. Build a mental model of the current state before proposing changes
4. Plan and confirm with the user before executing
5. Execute in phases, committing after each

If a procedure exists for what you're about to do, follow it. This prevents the "dive in and break things" failure mode.
